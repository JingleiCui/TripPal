# 本地模型一键准备与验收

在项目 `.venv` 环境直接运行 `scripts/setup_local.py`。配置集中在脚本顶部，正常使用无需命令行参数：

```bash
.venv/bin/python -u scripts/setup_local.py
```

脚本依次启动 Compose 服务、准备本地模型、保存配置备份、迁移数据库、检查实际模型能力、执行后端测试与 60 例工程回归、运行真实本地模型的三种规划策略和流式检查、执行真实旅行数据规划及单城/多城/锁定地点修改验证、构建前端、运行隔离浏览器测试，最后启动应用。任一步骤失败立即返回非零退出码；不会将“等待人工输入”写成完整规划成功。

`reports/local-setup/status.json` 是各阶段结果，完整日志在同目录；`reports/local-setup-run.log` 可作为重定向的总日志。校验成功的阶段按代码和配置指纹复用，避免重复推理；修改代码、配置或相应测试后自动重新执行。要强制全量重跑，把脚本顶部的 `REUSE_SUCCESSFUL_CHECKS` 改为 False。

## 模型与入口

| 能力 | 本地实现 | 准备方式 |
|---|---|---|
| 对话、工具、结构化输出 | Ollama `qwen3.5:9b`，8192 上下文 | 校验已有官方权重；缺失时由项目下载器下载并核对 SHA256；创建本地参数配置 |
| 截图识别 | 同一个 Qwen 多模态模型 | 复用已下载权重；通过本地视觉槽位调用，不另下一个视觉模型 |
| 向量检索 | `BAAI/bge-small-zh-v1.5`，512 维 | 复用 Hugging Face 缓存；缺失时下载 |
| 检索重排 | `BAAI/bge-reranker-base` | 复用缓存；缺失时下载；本次配置启用 |
| 中文转写 | `Systran/faster-whisper-small`，CPU int8 | 安装可选 `faster-whisper` 依赖并准备权重；请求时严格只读本地缓存 |
| 中文朗读 | macOS 已安装的 `Tingting` 声音 | 系统 `say` 生成音频，FFmpeg 转成 16 kHz 单声道 WAV；不调用云端 TTS |

可选语音依赖也可单独安装：`.venv/bin/python -m pip install -r requirements.local.txt`。系统需有 Docker、Ollama、FFmpeg；首次运行 Docker Engine 必须已启动。系统朗读适配当前只支持 macOS；其他系统会明确报告不可用，不会静默改用云端。

本机 `11434` 被另一个项目使用，因此此脚本默认在 `127.0.0.1:11435` 启动独立 Ollama 服务，模型目录为 `~/.ollama/models`。不停止其他项目的 Ollama，也不修改其他项目配置。独立服务保持运行供应用使用；脚本记录其启动 PID。

## 配置与数据隔离

脚本把完整本地配置写入 `config.local.json` 的 `model_profiles.local_complete` 并选中它，保留其他 profile 和平台凭证。修改前的配置备份保存到 `data/private-backups/local-setup`，权限为 0600。对话、结构化输出、截图、转写、朗读均通过原业务入口进入统一模型网关。

后端测试使用 `travel_agent_test`，评测使用 `travel_agent_eval`；浏览器测试服务使用独立端口 8818、测试数据库和测试 Redis DB，测试结束只关闭该脚本启动的测试进程。不会删除业务数据库、Docker 卷或旧模型。后端测试清理的 Redis DB 10/11 为已有项目专用测试库，请勿用于其他业务。

最后启动的正常应用使用 8808 和原业务数据库。启动时不固定 `TRAVEL_ACTIVE_MODEL_PROFILE`，因此后续仍可直接在配置文件切换 profile。更改 embedding 的模型时仍须自行执行索引迁移；本脚本使用原有 BGE 模型及 512 维索引，不换向量空间。

## 验收边界

所有模型推理均在本机执行，没有云端模型 API 费用；本地推理仍会消耗本机算力。首次下载模型需要网络。真实旅行数据规划需要已配置的旅行数据服务，地图和地点查询的网络请求不属于云端模型调用。

`scripts/validation/local_channels.py` 真实执行向量化、重排、朗读→转写，以及合成文字截图的实际模型识别；合成输入与模型真实输出分别标记。`scripts/validation/evaluate.py` 的 60 例默认回归使用合成供应商资料，是工程状态回归，不是 60 例真实模型质量评测。另有 `local-model-smoke` 验证三种策略的真实本地模型调用；`scripts/validation/plan.py` 使用真实旅行数据，必须达到 completed 才通过。

普通浏览器套件有两个需要额外专门数据和授权开关的 live 用例，默认跳过并在报告中列明；不能把跳过用例写成通过。系统声音、语音识别和截图提取的准确率仍需结合真实输入评估，所有识别结果继续要求用户确认。
