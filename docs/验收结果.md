## 数字口径

- 60／60 是**合成工程状态匹配**，没有模型，不是智能体质量、用户满意度或生产成功率。创建数据者知道规则，不能当作独立盲测。
- 本地模型冒烟：同一个 city-01 合成场景，纯模型 20.381 秒／1 次模型／0 工具；单 Agent 28.061 秒／5 次模型／5 工具；按需多 Agent 35.997 秒／8 次模型／5 工具。是单次观测，不是 P95，未控制三者冷／热状态，不能用来证明哪种策略普遍更优。
- 冒烟报告：reports/local-model-smoke-dc1034b0a3ae4d5f8d72dab3cde90411.json。语义质量未独立评阅，纯模型输出也不按结构缺失直接判失败。
- API 小样本：空行程账号、预热后 GET /api/v1/trips，30 请求／并发 4，P50 7.99 ms、P95 9.78 ms。只代表该端点这次本机观测，不代表 Agent 延迟或系统容量。
- reports/performance.json 包含逐请求样本、容器 CPU／内存与整机内存压力；ES 的实际占用与 JVM 堆不是同一个数字。模型载入也共享统一内存。

## 已知能力边界

当前解析器不提取图片、扫描页和复杂图表含义；日期外天气、景点内部步行、住宿接驳与实时预约库存可能未知。停留时长属于计划估计，开放窗口不是静态 POI 一定能提供的字段。约束冲突可以暂停请求取舍，不做自动付款或山野安全承诺。

未具备凭证前，用户仍可运行明确标注的合成流程，学习任务状态、图流程、版本、检索和恢复；不能用它证明真实旅行数据链路已经通过。
