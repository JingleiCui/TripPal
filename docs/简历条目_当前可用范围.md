# 项目经历（当前可用范围）

travel_agent｜中国旅行规划与行程协同助手（个人项目）

项目背景：面向国内自由行，将目的地、日期与出行偏好整理为可查看、可修改的旅行计划，集中展示日程、地图入口、信息来源和待确认事项，减少在多份攻略之间反复整理的操作。

技术栈：Python、FastAPI、LangChain、LangGraph、MySQL、Redis、Celery、Elasticsearch、React、TypeScript。

- 独立完成行程工作台与后端业务接口，支持行程版本、锁定安排、历史恢复、PDF 路书及可撤销只读分享，修改时校验日期、时间和基准版本，避免覆盖已确定安排。
- 基于 LangGraph 构建需求确认、按需领域调查、行程编排与约束检查流程；封装类型约束工具，加入执行预算、有限重试、检查点和调用记录，并用本地模型实际验证工具调用链路。
- 使用 MySQL 任务回执、租约与执行 token 配合 Celery 异步执行，处理重复投递、取消、过期接管及版本冲突；通过故障与重放测试验证业务结果不被重复提交。
- 构建用户隔离的私人攻略检索，使用 BGE 与 Elasticsearch 全文／向量召回、RRF 融合，保留来源位置并通过版本发布和权限过滤控制可见内容。

投递前边界：真实高德、Gemini、美团和语音平台能力需实际联调后再补入成果；当前不能写成已有真实用户、完成生产上线或显著提升旅行效率。60 条合成回归和本地模型冒烟分开说明，不写“Agent 成功率 100%”。
