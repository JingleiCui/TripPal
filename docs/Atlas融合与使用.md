# Atlas 融合与本机使用

## 启动及体验

在 PyCharm 打开 `travel_agent`，使用项目 `.venv`，运行根目录 `run_project.py`。页面 `http://127.0.0.1:8808/`。修改配置后先运行 `stop_project.py`，再重新启动；不会终止其他项目进程。

进入“对话规划”，没有平台凭证时勾选“使用合成资料体验”，输入“去北京”，再回答“三天，直接规划”。目的地和天数是硬门槛；不补充日期则只生成待确认草案，不伪造开放时间或实时可订信息。勾选对比后，A/B 候选仅暂存，选择后才提交行程版本。

“北京两天、上海两天，直接规划”可体验多城市。每一天只安排所属城市的地点；跨城市交通尚未获得实际查询结果时标为待核实，不用城市内导航伪装成高铁或航班。右侧画布可查看天数、候选与行程，手机端切换对话／画布。

## 功能与工程证据

| 功能 | 处理方式 | 验证 |
|---|---|---|
| 确定性访谈 | 模型提取事实，代码决定下一问；已知槽位不被空字段清除；可选问题一次询问 | 门控单元测试、浏览器两轮对话；20 次确定性更新保持条件，非 20 轮真实模型质量评测 |
| 对话与画布 | 会话、消息、行程持久化，候选和正式版本区分 | 浏览器选择方案后刷新恢复 |
| A/B 与再生成 | 共用研究结果，再生成不同排序，逐个校验；选择事务检查基线版本 | 候选不提前写入、重复选择幂等、选另一方案返回冲突 |
| SSE | 持久事件 ID、断线续读、阶段事件、真实提供者分块；A/B 带独立标识 | 合成模型分块契约测试；真实模型冒烟另见报告 |
| 协作 | 按行程 membership 授予 viewer/editor；模型无权填写身份 | 只读、编辑、撤销权限接口测试，执行前及提交前再次检查 |
| 账号 | 签名 JWT＋数据库可撤销会话、密码哈希、CSRF；邮箱单次令牌 | 本地 SMTP 真实投递、验证重复使用拒绝、重置使旧登录失效 |
| 邮件 | MySQL Outbox；本机 Mailpit SMTP 11026，收件箱 `http://127.0.0.1:18026` | 仅本地合成邮箱，不发送外部邮件；尚未验证真实 SMTP |
| 个性化 | 显式偏好、行为信号与评分；画像仅供建议，明确条件优先 | 默认目的地／天数播种、画像接口；中立评分不视为拒绝 |
| 统计 | 同意＋有效 PostHog key 双开关，关闭时不发统计请求 | 双开关关闭路径测试；尚未发送实际 PostHog 项目数据 |
| 隐私 | 全量个人数据 ZIP；删除 SQL、检查点、文件、索引；索引故障保留持久清理任务 | 导出、注销、旧登录拒绝、外部清理失败后重试测试 |
| 语义缓存 | ES512维 BGE，用户／城市／条件／提供者版本隔离，TTL1小时、相似度0.94 | 实际 BGE 与 ES 测试命中及跨用户／条件不命中 |
| 地图 | 高德日色图钉、路线和用户选择酒店；统一坐标系 | 真实 SDK、地点图钉、路线及酒店标记浏览器联调通过；当前无界面浏览器截图底图仍为灰色网格，不能宣称底图完整渲染通过 |
| 分享与导出 | 随机令牌、有效期、撤销；服务器生成 PDF，成员分享独立授权 | 浏览器下载、分享和撤销；本机地址不等于公网分享 |

## 平台配置

按 `平台申请与配置.md` 填写忽略版本控制的 `config.local.json`。高德分别使用 Web服务 Key、Web端(JS API) Key及安全码；美团 Token 保存在官方 CLI 配置；Google AI Studio 的 Gemini Key 使用原生 Gemini 客户端。不要将密钥发到聊天。

真实模型输出才产生 token 事件；合成体验整段显示模板，并明确标注。不将模板逐字播放称为真实推理流。

## 实现入口

- `conversation.py`：槽位提取、门控、中文适配。
- `social_api.py`：会话、SSE、协作、候选选择。
- `agent/graph.py`：调查、排程、约束检查、候选及答复。
- `agent/harness.py`：调用预算、租约、权限复查、模型流。
- `personalization.py`：中文行为映射与画像建议。
- `research_cache.py`：ES 研究缓存。
- `security.py`、`lifecycle_api.py`、`mailer.py`、`privacy_cleanup.py`：账号与数据生命周期。
- `frontend/src/ConversationWorkspace.tsx`：对话画布；`MapPanel.tsx`：高德地图；`AccountLifecycle.tsx`：隐私设置。

## 限制和后续验证

当前是个人学习项目的本机验证，不是企业上线成绩。已读取高德、Google、美团凭证，高德地点／天气及美团查询通过。Gemini 返回当前地区不支持 API，请按 Google 官方可用地区说明处理后再验证完整真实模型链路，单独观察配额、超时和价格字段。真实游客体验、跨城市交通查询、完整 60 例三策略模型质量对照和公网部署不能由现有合成回归结果替代。

账户删除不会自动改写离线备份；公开发布前需明确保留策略、独立 HTTPS 配置、外部 SMTP、JWT 密钥和邮箱强制验证。PostHog 属于可选能力，默认不启用。
