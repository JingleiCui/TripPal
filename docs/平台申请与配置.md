# 平台申请与配置

核对日期：2026-11-12。服务可开通、试用额度、期限及付费能力以你的控制台为准，不承诺永久免费。

## 1. 先准备本机配置

项目根目录已生成 `config.local.json`，被 Git 忽略，权限为仅本人读写。用 PyCharm 编辑这个文件，不要把密钥发到聊天、提交到 Git 或填进前端源码。

```json
{
  "model_api_key": "你的百炼API Key",
  "model_base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
  "model_name": "qwen-plus",
  "model_enabled": true,
  "amap_key": "Web服务Key",
  "amap_js_key": "Web端JS Key",
  "amap_security_code": "JS安全密钥",
  "meituan_enabled": false,
  "voice_enabled": false
}
```

修改后停止并重新运行 `run_project.py`，同时更新 API 和 worker 的配置。健康页“已配置”只代表存在配置，实际调用通过后才能记为“已验证”。

## 2. 高德地图（必需）

入口：https://lbs.amap.com/ ，登录后进入控制台。

1. 注册个人开发者并完成个人实名认证，确认个人研究学习用途及服务协议。
2. 在应用管理创建 `travel_agent` 应用。
3. 添加 **Web 服务** 类型 Key，写入 `amap_key`。后端用它查询地点、地理编码、路线和天气。
4. 再添加 **Web 端（JS API）** 类型 Key，写入 `amap_js_key`；相关安全密钥写入 `amap_security_code`。
5. 按控制台要求设置开发域名或来源限制，覆盖实际使用的 `127.0.0.1`／`localhost`。后端通过受限代理提供安全码相关请求。
6. 先进行地点查询，再验证地图渲染、公共交通和驾车路线。某种能力未授权时单独记录，不能把接口缺失算作“没有结果”。

JS Key 与 Web 服务 Key 类型不可混用。HTTP 200 不代表业务成功，要检查高德 `status` 和 `info`。无图片、开放时间或票价是可能的，不补造。地图和接口使用 GCJ-02；外部 WGS-84 数据需要转换后才能叠加。

官方说明：https://lbs.amap.com/upgrade

安全配置：https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode

## 3. Gemini（你选择的模型平台）

如果密钥来自 Google AI Studio，打开根目录 `config.gemini.example.json`，把内容复制到 `config.local.json`，替换其中的中文占位内容。`model_provider` 使用 `gemini`，走 Google 原生客户端，保留工具调用的消息信息；不是把 Google Key 发到百炼。

示例模型 `gemini-3.8-flash` 来自当前官方模型列表。以你的账号实际可用模型为准；也可以换成你已经能调用的模型准确名称。官方模型列表：https://ai.google.dev/gemini-api/docs/models

如果密钥来自第三方 OpenAI 兼容平台，则 `model_provider` 使用 `openai`，`model_base_url` 填该平台提供的兼容地址，`model_name` 填它要求的准确模型名，不照搬 Google 原生配置。不要把 ChatGPT／Gemini 网页会员账号当成 API 凭证。

官方 Gemini 通常不需要填写 `gemini_base_url`；原生代理地址可单独配置，网络需要能访问对应服务。API 是否可用仍需一次实际验证，Key 有效不代表所有模型都有额度。

高德两把 Key 推荐命名为 `travel_server`（Web 服务）和 `travel_web`（Web端 JS API）。如果页面要求 SHA1、PackageName，说明仍选择了 Android 类型，切换服务平台后不用填写这些字段。

美团 Token 名称使用 `travel_agent` 即可，只是备注。本机已准备 `/Users/cuijinglei/.config/meituan-travel/config.json`；在其中的 `key` 字段填入 Token。完成后把项目配置的 `meituan_enabled` 设为 true。已有文件不由启动脚本覆盖。

## 4. 百炼（可选替代平台）

入口：https://bailian.console.aliyun.com/

1. 注册阿里云个人账户并按要求实名认证，开通百炼模型服务。
2. 选择北京地域，检查 `qwen-plus` 的模型可用性、价格和试用额度。
3. 进入 API Key 管理，创建项目专用 Key。保存一次性显示的完整凭证。
4. 使用北京地域的兼容地址 `https://dashscope.aliyuncs.com/compatible-mode/v1`。不要混用其他地域 Key、Token Plan 专属凭证和通用接口。
5. 检查“免费额度用完即停”和费用提醒。没有额度时不要为了验证先购买套餐，先决定调用预算。
6. 把 Key 写入本机配置，开启 `model_enabled`。运行项目后先用一日行程进行少量调用，查看 Trace 的实际模型调用、Token 与延迟。

官方指南：https://help.aliyun.com/zh/model-studio/get-api-key/

额度说明：https://help.aliyun.cn/zh/model-studio/new-free-quota

### 本地模型对照

可把地址设为 `http://127.0.0.1:11434/v1`、Key 填本地占位值 `ollama`，模型设为 `qwen3:4b-instruct`。这不会访问云端计费，但必须实测工具遵循；不能因为能够输出文本就认为 Agent 已通过验收。

## 5. 美团酒旅（推荐）

官方能力：https://developer.meituan.com/ai-hub/skill-list/detail/12

Token 入口：https://developer.meituan.com/zh/v2/dev/token

1. 进入开发者中心，选择个人开发者并完成所需认证。
2. 查找官方 `meituan-travel` Skill，核对个人账户可授权的实际能力。
3. 创建 Token。项目已在 `integrations` 中固定安装官方 `@meituan-travel/travel-cli@1.0.16`，不需要全局安装。
4. 按官方 CLI 要求，在本机 `~/.config/meituan-travel/config.json` 写入 `{"key":"你的Token"}`，并将该文件权限设为仅本人读写。不要改写其他已有配置，已有 Token 可自行检查是否适用于本项目。
5. 在项目私密配置中设 `meituan_enabled: true`，重启服务。
6. 先验证一条酒店查询。它可能需要 1—2 分钟，项目超时为 180 秒。鉴权失败不会暴露原始 stderr 或 Token。

平台返回的价格字符串原样保留，例如 `￥4XX起/晚` 不能还原为 400 元。跳转链接不代表已预订。个人 Skill 的授权与商家分销 API、订单接口不是同一件事。

## 6. 小红书、大众点评、微信

- 小红书：首版导入用户自己的文字攻略、文字 PDF 或 DOCX。仅保存链接不代表已读取其内容；截图及扫描页需要另行文字提取，目前解析器明确显示这一缺口。不申请私有接口、不保存 Cookie、不批量抓取私人内容。
- 大众点评：仅使用实际获准的能力和来源链接，美团 Token 不默认等于点评全部接口授权。
- 微信：当前使用手机网页、手动复制链接和路书分享，不需要微信开发者账号。公网分享要有可访问的 HTTPS 服务；本机回环地址无法让朋友在手机上访问。JS-SDK 分享卡片、登录、支付属于后续独立接入。

## 7. 语音阶段

语音与旅行规划共用后端。已提供 Qwen ASR/TTS 适配代码和 FFmpeg 归一化，默认关闭，真实接口尚待凭证验证。使用 Gemini 对话 Key 时不会把该 Key 发往百炼；语音需要单独配置 `voice_api_key`。浏览器语音识别不能冒充后端模型部署经验。

## 常见问题

| 现象 | 核查 |
|---|---|
| 地图不出现 | JS Key 类型、来源限制、安全码、脚本网络、代理请求 |
| 地点可查但公交不可查 | Web 服务授权、城市参数、交通方式和平台错误码 |
| 已配置但模型失败 | 地域、兼容地址、模型名、余额、限流、工具调用支持 |
| 美团超时 | Token、本机 CLI、180 秒上限、原始返回是否为空 |
| 资料上传后搜不到 | 解析／索引状态、ES 健康、BGE 缓存、图片是否实际提取 |
| 分享无法跨设备打开 | 本机地址不是公网地址；检查部署和 HTTPS |
