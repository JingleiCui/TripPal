## OpenRouter 真实 key 联调 + 按用途分槽位（已落地，修正上一轮的占位模型名）

- **概念澄清（用户提问点）**：`openrouter_free` 只是本机 **profile 名**；上一轮写在 `model_name` 的 `openrouter/free` 是 OpenRouter **真实存在的免费模型自动路由器**，不是占位符，但不该作默认——本机同一轮三次请求分别路由到 `particle-1` / `nemotron-3.5-lightning` / `nemotron-3-ultra`，`json_schema` 与 tool calling 行为不可复现。已改为具体 `:free` 模型。
- **实时目录实测**：`GET /api/v1/models` 返回 471 个模型、17 个免费；按能力元数据 + 真实最小调用筛选。Ling(`inclusionai/ling-3.2-flash:free`) chat/json_schema/tools 全通；Nemotron VL 视觉输入通过但 json_schema 会耗尽 8192 tokens；ERNIE preview **强制 reasoning**（关闭返回 400）且长链路 `LengthFinishReasonError`，本项目不用；Gemma 上游 429。
- **修复架构洞**：上一轮宣称「model_slots 按槽位混搭供应商」，但 `structured` 槽位只影响 `structured_method`，`generate()` 仍走 chat 实例。改 `harness.model(slot="chat")` → `gateway.chat_model(slot=...)`，`generate()` 调 `model("structured")`；`_structured_method` 让 slot override 优先于全局；`MODEL_PROFILE_FIELDS` 放行 `model_slots`，**profile 自带槽位分配**，切回本地 `current` 自动还原（顶层 model_slots 是全局的，不能乱写）。
- **新增 `extra_body` 一等配置**（ProviderSpec / SLOT_FIELDS / ResolvedSpec + fingerprint / gateway 的 ChatOpenAI 构造与 `_post` 请求体两条路径）。用途：`{"reasoning":{"enabled":false}}`。这是本轮最关键的修复——免费 reasoning 模型默认把 `max_tokens` 耗在隐藏思考上，导致 `finish_reason=length` / `LengthFinishReasonError` / `OpenAITimeoutError`（一次调用 312s）。厂商相关参数，ERNIE 不接受，只给实际选用的槽位配。
- **自检脚本修正**：`--probe-vision` 原来的 1×1 PNG 被 provider 以 "media could not be screened" 拒绝，属假失败；改为生成有效 160×60 PNG。
- **最终配置**（`config.local.json` 的 `openrouter_free` profile，key 已由用户填好，`active_model_profile` 仍是本地 `current` 未改）：chat/structured/vision 均 `inclusionai/ling-3.2-flash:free` + 关闭 reasoning；`model_output_tokens=4096`；推荐组合（视觉用 `nvidia/nemotron-3.5-super-vl:free`）保留在 `config.openrouter.example.json` 与文档。降级原因：账户级 `free-models-per-day` 日额度在密集自检后耗尽，Nemotron/dots/particle 全部 429，只有 Ling 桶仍可用；额度恢复后把 `model_slots.vision.model` 换回即可。
- **真实验证**：`check_providers.py --profile openrouter_free --probe --probe-vision` → chat / structured(json_schema) / tools(1 call) / vision 全 OK；`TRAVEL_ACTIVE_MODEL_PROFILE=openrouter_free scripts/smoke_plan.py` → `completed`，行程 version 1「北京 · 1 日城市行程」（一次 interrupt + 自动 resume）。离线：`pytest -q` **158 passed**（新增 4 条：槽位隔离、profile 自带 slots、extra_body 两条路径）、ruff 全绿、`npm run build` / `format:check` 全绿。
- **诚实边界**：OpenRouter 已真实联调，但不等于所有 `:free` 模型可用；换模型必须重跑 `--probe` + `smoke_plan`。`asr`/`tts` 仍需百炼凭证；ES 语义缓存测试索引仍报非致命 400。
